# v1.1 — What's New

[English](#english) | [繁體中文](#繁體中文)

## English

v1.1 is the stable release of the routing, exit shutdown, and subscription improvements first documented during the beta. The [beta notes](v1.1-beta.md) remain available as a development record.

### Highlights

- Native nginx hostname maps replace sequential suffix regular expressions. Exact and suffix rule conflicts resolve by priority, then rule ID; matching is case-insensitive.
- **Publish → Test domain routing** shows which saved rule and exit a domain would use. It previews unpublished changes and does not test live VPN connectivity.
- **Exits → Stop All** stops VPN exits and relays while preserving routing rules and subscriptions. Scheduled restarts leave manually stopped exits alone.
- Subscription sync accepts `DOMAIN-SUFFIX` entries, normalizes and deduplicates domains, limits downloads to 10 MiB, and writes rule changes in a transaction.

### Upgrade notes

Overlapping exact and suffix rules may select a different exit because priority is now applied consistently. Review important domains with **Test domain routing** and **Preview Config** before publishing. Stopped exits must be started again before their routes work. See the [update guide](../UPDATES.md) for deployment and recovery steps.

## 繁體中文

v1.1 是網域路由、出口關閉與訂閱同步改進的正式版。先前的 [beta 更新紀錄](v1.1-beta.md) 保留作為開發歷程。

### 主要更新

- 改用 nginx 原生 hostname map，取代逐條後綴正則匹配。精確與後綴規則依優先級、再依規則 ID 決定結果；匹配不分大小寫。
- **發布 → Test domain routing** 顯示已儲存規則會為網域選用的規則與出口。結果包含尚未發布的變更，不代表實際 VPN 連線測試。
- **出口 → Stop All** 停止 VPN 出口與 relay，同時保留規則及訂閱。定時重啟不會重新啟動手動停止的出口。
- 訂閱同步支援 `DOMAIN-SUFFIX`、統一網域格式與去重、限制下載檔案為 10 MiB，並在資料庫交易中寫入規則變更。

### 升級注意事項

精確與後綴規則重疊時，現在會一致依優先級選擇出口，因此部分網域的結果可能改變。發布前請用 **Test domain routing** 與 **Preview Config** 檢查重要網域。已停止的出口須重新啟動，相關路由才會恢復。部署與復原步驟請參閱[更新指南](../UPDATES.md)。
